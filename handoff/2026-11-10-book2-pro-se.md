# Galaxy Book2 Pro SE in Supported hardware

PR #NUMBER · Claude · 2026-11-10

## What changed
- `docs/supported-hardware.md`: a paragraph on the Galaxy Book2 Pro SE (`950XGK`, `05a1`), and the Book3 note no longer says `G` always means the Book4.

## Why
- Abdallah's issue #4 reports the Book2 Pro SE working on Ubuntu 26.04 with his driver, the one this fix builds. Its model code has `G` after the `X`, like the Book4, so the Book3 check lets it install.
